# Expense Tracker

A simple desktop-based **Expense Tracker** built using Java Swing.

The application allows users to record daily expenses, organize them by category, calculate total spending, view category-wise analytics, and check expenses for the current month.

## Features

- Add new expenses
- Select expense category
- Enter expense amount
- Enter expense date
- View expenses in a table
- Delete expenses
- Calculate total expenses
- View category-wise analytics
- View current-month spending
- Save expenses locally
- Load saved expenses when the application starts

## Categories

The application supports the following categories:

- Food
- Travel
- Shopping
- Education
- Bills
- Other
